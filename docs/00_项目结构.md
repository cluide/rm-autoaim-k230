# 项目结构与文件配置（你自己动手写之前，先把这张图和三条铁律看完）

## 1. 目录树

```
rm_autoaim_k230/
├─ k230/                     ← 全部要拷到板子 /sdcard/app/ 的东西
│  ├─ main.py                ← 唯一入口：建对象 + 死循环
│  ├─ config.py              ← 所有可调参数（只放常数，不放逻辑）
│  ├─ camera.py              ← 硬件边界：sensor 取帧 → 返回 nn 能吃的数组
│  ├─ detector.py            ← 硬件边界：封装 libs.YOLO，输出统一格式的框
│  ├─ uart_link.py           ← 硬件边界：跟电控收发帧、校验、解析
│  ├─ geometry.py            ← 纯算法：坐标变换、像素↔3D、角度解算
│  ├─ ballistics.py          ← 纯算法：弹道表 + 仰角求解
│  ├─ tracker.py             ← 纯算法：卡尔曼滤波（世界系）
│  ├─ logic.py               ← 纯算法：选目标、算指令、判开火（业务大脑）
│  ├─ compat.py              ← MicroPython/CPython 兼容（ticks_ms 之类）
│  └─ selftest.py            ← 板端自检：不开相机、不接串口，验证纯算法
├─ tools/                    ← 只在电脑上跑，不拷到板子
│  ├─ export_onnx.py         ← .pt → .onnx
│  ├─ convert_kmodel.py      ← .onnx → .kmodel（nncase）
│  ├─ calib_intrinsics.py    ← 相机内参标定（OpenCV）
│  └─ sim_logic.py           ← 在电脑上用假数据跑 logic.py，验证算法
├─ model/                    ← 训练产物、kmodel、标定结果 json
├─ logs/                     ← 打靶记录、串口抓包、帧率日志
└─ docs/                     ← 这份笔记
```

板子上只需要 `k230/` 里的 `.py` 和 `model/*.kmodel`。**tools/ 和 model/ 的原件永远留在电脑上**，别往板子塞。

## 2. 三条铁律

### 铁律一：硬件只能出现在"边界文件"里

只有 `camera.py`、`detector.py`、`uart_link.py` 允许出现
`from media.sensor import *`、`from libs.YOLO import YOLOv8`、`from machine import UART`。

`geometry.py` / `ballistics.py` / `tracker.py` / `logic.py` **一行都不许** import 硬件。

为什么？两个好处，第 2 天你会感谢自己：

1. 纯算法能在电脑上用 CPython 跑。相机还没装好、板子还在排队的时候，你的坐标系、
   滤波、弹道逻辑就已经写完并验证过了。K230 上调试算法的心智负担是电脑上的 5 倍。
2. 算法出错时，你能确定问题不在硬件。

反例（新手最常见的死法）：`logic.py` 里顺手写了一行 `print(sensor.snapshot())`，
然后电脑上跑不了、板上又分不清是算法错还是取帧错，两天就没了。

### 铁律二：所有可调参数集中在一个 config.py

不许出现这种代码：`if d_yaw < 0.006:`。必须是 `if d_yaw < C.FIRE_YAW_TH:`。

为什么？第 3 天你会有 20 多个参数要调。散落在 6 个文件里的常数，
你连"我刚才到底改的是哪个"都记不住，调参就是随机游走。

### 铁律三：每个文件都要能"单独验收"

写完一个文件，它必须有一个不用整个系统跑起来就能看的输出。
例如 `detector.py` 写完，就在 main 里只做"取帧→检测→把框画到屏幕"，
别的什么都不做。**这一层对了，再往上叠一层。**

这也是 `selftest.py` 存在的唯一理由：晚上 11 点你改崩了算法，
用它 5 秒就能确认"是纯算法坏了，还是硬件坏了"。

## 3. 模块接口契约（先定好签名，再写实现）

照着这个写，以后换实现不用改别处。

```python
# camera.py
class Camera:
    def __init__(self, w, h, fps)      # 建 sensor
    def get(self)                      # 返回 nn 能直接吃的帧（CHW ndarray）；没帧返回 None
    def deinit(self)

# detector.py
#   统一输出：list[tuple]，每个元素 (x1, y1, x2, y2, score, cls)，单位像素，浮点
class Detector:
    def __init__(self, kmodel, labels, imgsz, conf, nms)
    def detect(self, frame) -> list

# geometry.py   （纯函数，无状态，最好测）
def cam_to_world(p, yaw, pitch) -> (x, y, z)
def world_to_cam(p, yaw, pitch) -> (x, y, z)
def dir_to_angles(w) -> (yaw, pitch)
def armor_to_cam(x1, y1, x2, y2, cam_intr, armor_h) -> (x, y, z) 或 None
def wrap_pi(a) -> float

# ballistics.py
class BallisticSolver:
    def __init__(self, v0, k)
    def solve_pitch(self, L, h) -> 仰角
    def time_of_flight(self, L) -> 秒

# tracker.py
class Tracker:
    def update(self, pos_world, now_s)
    def predict_at(self, now_s, horizon_s) -> (x, y, z)
    def reset(self); def is_valid(self)

# uart_link.py
class Link:
    def poll(self, now_ms) -> (yaw, pitch, bullet_speed) 或 None
    def send(self, d_yaw, d_pitch, dist, fire) -> None

# logic.py
class AutoAim:
    def step(self, dets, gimbal, now_ms) -> dict  # {'d_yaw':.., 'd_pitch':.., 'fire':.., 'dist':..}
```

`logic.py` 是唯一"知道所有模块"的文件，`main.py` 只做连线：

```python
while True:
    frame = cam.get()
    dets = det.detect(frame)
    g = link.poll(now)
    cmd = brain.step(dets, g, now)
    link.send(**cmd)
```

`main.py` 超过 60 行，说明你把业务逻辑写进循环里了，挪回 `logic.py`。

## 4. 板上文件怎么放

```
/sdcard/app/          ← 所有 .py
/sdcard/kmodel/*.kmodel
```
CanMV 的 import 走当前工作目录 + `/sdcard`，所以最简单的做法是：
**所有 .py 平铺在同一个目录**，`import geometry` 就能找到，不要搞子包。

（真要分子目录，得在 `main.py` 开头 `sys.path.append("/sdcard/app/lib")`，
第 1 天别给自己找麻烦。）

拷文件用 CanMV IDE 的"保存到开发板"，或者拔卡用读卡器。
**改完 .py 记得 IDE 里"运行"是热重启，但 kmodel 换了必须重新上电。**

## 5. 依赖方向（画出来，别画反）

```
        config.py
            ↑
  ┌─────────┼─────────┐
geometry  ballistics  tracker        （纯算法层，互不依赖）
  └─────────┼─────────┘
            ↑
        logic.py                     （业务层，只依赖上面三兄弟 + config）
            ↑
          main.py
         ↑       ↑
   camera.py  detector.py  uart_link.py   （硬件层，只被 main 调用）
```

箭头只能向上。`geometry.py` import `logic.py` 就说明分层塌了。

## 6. 命名约定（省你自己时间）

- 变量带单位后缀：`d_yaw_rad`、`dist_m`、`t_ms`、`h_px`。单位混用是自瞄第一大 bug 来源。
- 世界系变量以 `_w` 结尾，相机系 `_c`，机体系 `_b`：`p_w`、`p_c`。
- 像素坐标永远用 `u, v` 或 `x1, y1, x2, y2`，别用 `x, y`（会和 3D 的 x,y 撞车）。

## 7. 现在就可以动手的第一步

先只写 `config.py` + `camera.py` + `detector.py`，`main.py` 里只做一件事：

```python
while True:
    frame = cam.get()
    dets = det.detect(frame)
    print(len(dets), dets[0] if dets else None)
```

跑通、稳定 30fps 以上、框的位置肉眼对得上 —— **第 1 天的第一关就算过了**。
在这之前不要去看坐标变换，看了也用不上。
